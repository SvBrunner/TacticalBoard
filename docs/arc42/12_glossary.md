# 12. Glossary

| Term | Definition |
|---|---|
| Board | The drawable canvas representing a game situation: players, ball, objects, and lines. Exportable/storable as JSON. |
| Situation | A saved game scenario — either a standard set-piece or a freely drawn one — represented by a board. |
| Team | A group of users who share access to boards and folders, with per-member roles. |
| Folder | Groups a team's boards for organization. |
| Role | A team-scoped permission level: Admin, Bearbeiter (editor), or Leser (reader). See ch. 8 for the (draft) permission matrix. |
| Trainer | A coach-type user of the system. |
| Spieler | A player-type user of the system. |
| IdP (Identity Provider) | External, self-hosted service handling authentication (e.g. PocketID, Keycloak). The backend does not store passwords itself. |
