# 1. Introduction and Goals

## 1.1 Requirements Overview

**Functional requirements**

Board:
- Display a tactical board.
- Manage players, ball, objects, and lines on the board.
- Export a board as JSON.

Server-side board management:
- Save a board on the server.
- Load a board from the server.
- Edit a board on the server.
- Delete a board on the server.
- Access boards belonging to a team.
- Group boards into folders.

Teams:
- Create a team.
- Join a team.
- Leave a team.
- Manage team members.

**Non-functional requirements**

- Usability in the browser, on both mobile and desktop.
- Performance.

## 1.2 Quality Goals

1. Usability across devices (mobile and desktop browsers).
2. Performance.

_Not yet ranked beyond this order — revisit if the two ever trade off against each other._
